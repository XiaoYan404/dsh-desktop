# 企业工作台 · PyQt 工作台原型 V0.8

2026-10-15 更新：通讯录聊天采用独立微信式窗口，消息气泡与输入区分开，表情、文件、任务、会议、待办功能位于输入框上方。AI 会话可以关联系统和工具，展示标签、配置状态与每次发送时的关联记录；首页右侧增加可点击、可暂停的滚动公告。

## 一键预览

双击本目录 **启动原型.cmd**，打开独立桌面窗口。重复双击会唤起已有窗口。退出时直接关闭窗口。

边设计边看效果时，双击 **启动实时预览.cmd**。保存 `app.py`、`workbench_ui.py`、`prototype_model.py` 或 `qt_widgets.py` 后，约 1 秒内自动重启预览。连续保存会合并处理；重复打开启动器只唤起已有实时预览。关闭实时预览窗口后，监听进程也会退出。

实时预览是开发用的自动重启，不是正式产品热部署。外观偏好会保留；代码重启后演示任务和会话按初始状态重新载入。实时预览使用独立的 `.preview-data/live/`，普通预览继续使用 `.preview-data/`。

保存含语法错误的代码时，仍在运行的预览保持打开，并显示开发提示；修复保存后会重启到新版本。启动时的运行错误也会显示提示并继续等待修复。缓存、日志、偏好写入和截图不会触发重启。修改启动器或监听器自身后，需要关闭并重新打开实时预览。

当前电脑已检测到 `D:\conda\python.exe`，Python 3.13.9 / PyQt5 5.15.11，无需再安装依赖。启动器会寻找目录内虚拟环境、PATH、Python Launcher 与注册表中的 Python；不自动修改环境。请把整个目录放在一起。

换电脑后需要 Python 3.9+；如果启动器提示缺少 PyQt5，在本目录终端执行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

依赖已安装后可以离线预览。当前交付是脚本启动的桌面原型，尚未打包为独立 EXE 安装包。

## 预览范围

使用原生 PyQt5 控件，左侧保留 72px 应用图标导航。七个主要按钮依次为工作台、AI会话、通讯录、网盘、工作、集成、工具；底部仍为团队、设置。搜索与新工作位于顶部。原有场景工坊和我的助手从“应用”菜单进入，工具页的“底层能力”保留原有插件配置演示。

左侧「AI会话」继续当前会话。右侧支持新建、搜索和切换会话，分别保存草稿、消息、资料名称与演示执行结果；“资料与成果”标签保留工作区与交付物操作。切换到其他会话会停止前一个尚未结束的模拟执行，点击当前会话不会停止执行。会话历史在本次运行内有效。

AI 输入区上方提供“关联集成”和“关联工具”。可以搜索并勾选公司系统或工作技能，保存后显示名称与配置状态，点击标签查看详情或取消关联。关联有依赖的工具时，自动关联已导入的对应系统插件；缺少系统、尚未关联或待配置时明确显示状态。关联配置分别保存在各个普通会话、事项会话与演示账号下，每次发送保留当时的关联记录，后续修改不改写历史。工具详情中的“在 AI 会话中使用”会为当前会话关联工具并填入要求，等待确认发送。

首页上方左侧 3/5 显示仪表板，统计本机当日的待完成、已完成、任务与待办、日程和完成进度，数据来自当前演示事项。右侧 2/5 合并一周日期按钮和今日事项列表，事项显示当前状态并按时间排列，无时间事项排在最后；已完成与已取消记录保留可见。点击事项查看详情，点击日期查看当天日历；“＋ 待办”位于日历按钮旁，空列表也有新建入口。

日历与待办下方显示滚动公告，自动轮换当前演示公告，鼠标悬停暂停，点击或键盘 Enter 查看发布人、日期与完整内容；无公告时显示空状态。

下方 AI 对话区与独立“AI会话”页共用当前普通会话。点击发送或按 Ctrl+Enter 后，带上内容和资料名称进入独立会话并立即开始模拟处理，无需再次发送；空输入不会跳转。点击“展开会话”只进入会话，不自动发送。返回工作台会保存关联事项的协助会话，再切回普通会话；不会把不同事项的草稿混在一起。输入区在 1040×700 小窗口下仍保持可见。

点击工作台右上角「日历」默认回到今天的日程与待办列表，也可从“应用”菜单进入。可以点击一周日期按钮、前后日期按钮或日期选择器查看其他日期。新建待办支持标题、负责人、日期、可选截止时间、说明与状态；空列表可直接新建待办或日程。待办状态为待处理、进行中、已完成、已取消；示例 OA 待办另有待补充。日历、工作列表和详情页均可修改状态，并同步首页列表与完成进度。列表保留各状态记录；日程显示起止时间、地点和参与人数。

点击「新建日程」填写标题、日期、起止时间、地点和说明，并勾选团队成员。发起人自动参与，成员邀请在详情中显示为「待回应」。创建今天的日程会同步出现在首页日历与待办中；创建其他日期的日程只显示在对应日期。日程详情可查看参与成员、返回原日期列表或进入独立 Agent 协助会话。邀请仅在本次原型中记录，不发送邮件、企业通知或真实日历邀请。取消或校验失败不会留下日程或邀请记录。

右上角显示头像、姓名、角色和岗位。点击头像可编辑姓名、角色、岗位、部门、邮箱和电话；“演示账号”可切换林晓、陈安、许宁，观察网盘权限与双向消息效果。不同演示账号的 AI 会话分别保存。这里的角色修改仅是资料演示，不代表修改真实企业权限。

「通讯录」按公司、部门展示成员，支持搜索姓名、部门和岗位。选择同事可发消息、派任务、约会议或建待办；任务与待办预选该同事为负责人，会议预选该同事为参与成员。点击发消息打开独立微信式聊天窗口，左侧可搜索与切换成员会话，中间显示头像和左右气泡消息；输入区上方放置表情、文件、派任务、约会议、建待办。发送后窗口保持打开，Enter 发送、Shift+Enter 换行，也支持 Ctrl+Enter。消息与附件名称可连续发送，不读取或上传附件正文。切换成员、关闭再打开、打开协作表单都会保留该账号对该成员的草稿和待发送文件名；切换演示账号关闭原聊天窗口并隔离草稿。消息在本次原型中双向记录，切换账号后可以查看和回复。

「工作」展示手头的日常工作，可按我负责的、我派发的、全部工作以及状态筛选。支持新建待办、派发任务、修改状态、查看详情和进入事项 Agent 协助。从通讯录派发的任务会出现在我派发的清单中。

「网盘」采用文件夹树、路径栏、前进后退、上一级和详细信息列表。双击或 Enter 打开文件夹，支持新建文件夹、添加文件、重命名、右键操作及将资料名称带入 AI 会话。私有网盘仅所属账号可见；共享网盘所有者可设置默认条件及每个账号的不可见、可查看、可编辑权限。文件继承上级条件；上级不可见时，下级内容也不可见。无权查看的文件不进入搜索结果，也不能带入会话；只读账号不能添加或重命名。权限当前由本地原型演示，正式部署需在服务端校验。

「集成」列出本公司系统插件，预置 OA、ERP、CRM、HR 示例，可查看系统说明、开发方、版本、业务负责人、功能和配置状态。支持导入 JSON 插件清单，最多 256 KB；“导入说明”提供格式示例与导出入口。必填字段为 name、system、version、provider、description、capabilities，owner 可选。导入只登记插件清单；填写系统地址后显示已配置、待联调，不代表已连接或执行插件。“联系产品公司定制”保存系统或技能需求草稿，未对外发送。

「工具」展示办公处理、沟通协作、审批流程、自动化技能，包含文档、表格、演示、PDF、钉钉、企业微信、会议纪要、OA 审批、报销检查与任务提醒。点击技能查看详情和关联集成，再将工作要求带入 AI 会话，等待确认发送。支持添加本次预览内的技能入口；实际系统能力需由连接器提供。

点击时间线事项先进入独立详情页，查看内容、发起人、负责人、时间、状态和示例资料。点击“让 Agent 协助”才进入聊天；事项作为上下文卡片带入，不自动发送消息或开始执行。每个事项的消息、草稿、附件名称和演示执行结果在本次运行中分别保留。普通会话也与事项会话分开。切换到另一会话时停止前一会话尚未结束的模拟执行，并记录停止提示。

原有场景、助手、底层能力与设置流程继续可用。会话输入支持 `Ctrl+Enter` 发送。“打开原系统”在未连接的演示事项中禁用，避免把演示记录误当成真实系统记录。

这是纯界面原型，业务使用本地演示数据，没有模型调用、后端、真实插件安装或企业消息发送。文件选择只记录名称、大小和类型，不读取正文或上传。导出内容明确为示例 TXT 或配置 JSON，不伪装为已生成的 Office 文件。真实执行进度、草稿成果交付、任务验收和系统连接留待后续迭代。

企业名、产品名、主题和密度保存在当前预览数据目录的 `preferences.json`；运行日志为 `preview.log`。实时预览另有 `live-status.json` 和 `live-preview.log`，供定位启动与重载问题。任务、资料、会话、个人资料修改、消息、权限、插件清单、技能与需求草稿在退出或代码重启后重置。用户主动导出的文件保存在选择的位置。

推荐 1440×900，最小窗口 1040×700。工作台上方保持 3:2 分栏，下方对话记录独立滚动、输入区固定可达；小窗口会降低上方区域高度。独立会话页在小窗口仍保留右侧会话栏；网盘缩小后隐藏修改日期列，为文件名留出空间。`Ctrl+K` 搜索，搜索框按下方向键选择结果，`Enter` 打开；`Alt+N` 新会话；`Esc` 关闭弹窗。事项卡可用 Tab 聚焦、Enter 或空格打开。菜单「视图」可切换主题、密度和全屏。
