# 企业工作台页面原型改造

> 当前预览版本为 **V0.8 原生 PyQt5 工作台**（2026-10-15）。请双击 `启动实时预览.cmd` 边改边看，或使用 `启动原型.cmd` 普通预览；详见 [PyQt使用说明](PyQt使用说明.md)。当前通过 63 项界面检查，重载机制沿用已验证的 V0.4 实现。以下保留早期版本的历史设计说明。

## 当前设计方向 · 工作台首页

左侧依次为工作台、AI会话、通讯录、网盘、工作、集成、工具，底部团队和设置保持不变。工作台首页上方按 3:2 分栏，左侧是当日工作仪表板，右侧合并日期与待办列表，下方为 AI 输入。首页点击发送或 Ctrl+Enter 后进入独立会话并直接发送，保留左侧导航；右侧提供新建会话、搜索、会话列表与资料成果标签。不同会话分别保存消息、草稿、资料与模拟执行结果。

待办在首页日历按钮旁和空列表中均可创建，可指定负责人、截止日期、时间和状态；日历、工作与详情修改状态后同步首页。右上角显示登录人的头像、姓名、角色与岗位，点击查看和设置个人资料。通讯录展示公司部门成员，可发消息、派任务、约会议或建待办。工作页以日常工作为主，支持我负责的、我派发的与状态筛选。

通讯录聊天使用独立微信式窗口，支持成员会话列表、左右消息气泡、连续发送和分别保存草稿；表情、文件、任务、会议、待办功能统一位于输入框上方。AI 会话可关联系统与工具，在输入区上方显示名称、配置状态和取消入口，并保留每次发送的关联记录。首页日历下方提供滚动公告，支持悬停暂停与查看全文。

网盘采用 Windows 文件夹式导航，分私有与共享空间，支持新建文件夹、文件元数据导入、重命名与右键菜单。共享文件和文件夹按账号设置查看或编辑条件，支持继承与不可见；切换演示账号可检查权限效果。系统集成展示公司的定制系统插件，支持导入清单、查看详情、保存待联调配置与记录产品公司定制需求。工具页展示文档、表格、钉钉、企业微信、OA 审批等技能，关联集成并将要求带入会话。

场景工坊和助手配置保留菜单入口。业务协作、账号、网盘权限、插件清单与技能均为本次运行中的本地演示，未连接企业系统、发送真实消息或执行插件代码。重启后重置业务数据，外观偏好保留；正式 Electron 项目与空的页面开发文档目录未改动。

## V0.5 历史设计 · 今日工作

布局收敛为 72px 图标导航与主画布，移除“远山科技”所在的空间侧栏，搜索和新工作移到顶部。新增独立的日历列表，默认展示当日日程，通过日期条切换当天内容；支持新建日程和多选参与成员。日程详情展示起止时间、地点与邀请状态，返回时保留所选日期。成员邀请和日程数据均为本次原型内的演示记录。

普通员工首页以时间线为主，按时间统一排列工作任务、企业系统待办和日程；没有明确时间的事项放在“待安排”。首页不再有聊天输入框，通过“与 Agent 对话”进入独立会话。

点击事项进入独立详情页，展示要求、来源、相关人员、时间和状态；再点击“让 Agent 协助”，将事项作为上下文带入独立会话，等待员工输入并发送。每项的会话、草稿、附件名称及演示执行结果在本次运行内分别保存。代码自动重启后，演示数据重置，外观偏好保留。

本轮仍使用虚构数据，原系统入口显示未连接状态。真实系统对接、Agent 执行、草稿交付及任务验收继续逐步设计。正式 Electron 项目与空的页面开发文档目录均未改动。

## V0.3 历史设计 · 工作台

用户反馈原界面质感不足，仍像管理系统。V0.3 将视觉与信息结构一起调整：应用工具栏只占 72px，旁边 208px 的空间侧栏展示项目、最近打开的工作和个人草稿；主画布优先呈现任务输入、当前工作与成果，宽窗口提供资料托盘。团队配置与偏好放在工具栏下方。

首页以「今天，想完成什么？」和可附资料的多行输入开始。下方「继续工作」直接展示 DOCX/PPTX 成果及工作阶段；「为工作准备的工具」作为次级入口。主页取消任务表格与管理指标。「我的工作」展示可点击、可键盘打开的成果卡；「资料架」展示文档封面，支持搜索、筛选和带入当前工作；「场景工坊」将资料、模板、助手组合成工作的起点。

视觉采用纸白、暖石色与少量青绿，深色主题使用墨石色。标题、正文和辅助文字建立字号层级；使用细线、圆角、留白及原生绘制的文档封面和图标，减少大面积品牌色背景与重复模块框。

当前会话草稿、附件与模板随导航保留；首页拥有独立草稿，开始工作时带入会话。完成工作的卡片是预置记录，不声称恢复真实历史；模型调用、共享知识和企业服务仍处于设计阶段。正式 Electron 项目没有在本次原型改版中修改。

版本：V0.1.10 · 2026-10-13。定位：基于 DSH Desktop Fork 的企业定制 PC 桌面应用。本文与 HTML 均为设计交付，不是业务功能实现。

## 2. 已确认需求与设计假设

已确认：面向企业的通用办公 Agent；保留 DSH Desktop 当前所有能力；增加企业包装与业务工作台；桌面 GUI 与 exe 安装形式保持；本轮只做设计原型。

设计假设：使用者包括普通员工、业务负责人和企业管理员。产品暂用「序 · 企业工作台」，示例公司为「远山科技」，可在企业管理页修改原型品牌。先突出销售分析、文档撰写、演示制作、知识问答四类工作。公司名、岗位、文件、任务、日期和统计数均为虚构样本。登录方式、组织服务端、计费方式、共享部署、实际品牌均未定案。

“保留所有能力”是后续实现的验收约束，不表示本次静态原型实现了底层功能。本次依据本地 Fork `115a0b4` 的 README、桌面菜单、已运行界面与插件包目录梳理入口。正式开发前仍须逐项走查完整上游配置、快捷键和插件页面，补齐未列出的入口，不能仅凭这张清单声称已完成兼容。

## 3. 产品结构

保持 Electron 宿主、Harness runtime、Harness Web UI 和现有数据生命周期。企业层提供品牌、默认导航、岗位入口、资料与模板组合。企业工作台复用现有工作台与 Preset 的能力，避免另写一套 Agent 执行引擎。

推荐信息架构：

| 一级入口 | 主要内容 | 设计意图 |
| --- | --- | --- |
| 工作空间 | 问候、自然语言任务入口、常用工作台、最近任务、待确认事项 | 员工打开应用后知道从哪里开始 |
| 企业工作台 | 分类、搜索、业务工作台、社区市场、自建入口 | 按业务组织既有工具和资料 |
| Agent 会话 | 原有对话、工具过程、附件、模型、PPT、交付物 | 保留通用 Agent 的自由使用能力 |
| 任务中心 | 任务状态、人工确认、历史记录、自动化入口 | 统一查看执行进度与产出 |
| 知识与资料 | 本地文件、分类、模板、拟新增共享知识 | 让任务所需资料容易找到 |
| Agent 中心 | Preset、企业助手、导入导出、工具与模型组合 | 复用岗位配置 |
| 插件与能力 | 官方/扩展/实验性分类、配置、启停、市场 | 完整高级能力可发现 |
| 企业管理 | 品牌、组织、角色、策略、审计设计 | 企业新增管理层 |
| 设置与连接 | 模型、工作区、主题、手机、更新、安全模式、隐私 | 保留桌面宿主功能 |

侧边栏保持工作与管理分组。企业管理在正式产品中按权限显示，但不能以隐藏菜单代替安全校验。当前原型以管理员视角展示全部入口。通用会话和高级功能始终保留，不因企业首页上线而移除。

## 4. 视觉与桌面交互

采用浅灰白内容底色、雾绿侧栏、远山绿主色 `#245C48`，辅以灰蓝、浅金区分工作台。使用系统字体，避免依赖在线字体或图片。图标为本地内联 SVG，首页插画由 CSS 绘制，离线可显示。

固定桌面标题栏、侧栏、顶部搜索和底部状态栏；内容区独立滚动。桌面菜单、最小化、最大化、关闭在正式产品中对接原有 Electron 行为。原型的最小化/关闭只解释行为，方框按钮切换布局密度，不关闭真实程序。

首页不以大量管理指标作为主视觉，优先放任务输入和业务入口。会话页采用主内容与右侧上下文双栏，集中展示工作区、参考资料、权限状态与交付文件。关键操作在执行位置确认，显示动作、目标和影响范围。

V0.1 设计桌面最小宽度 1040px、最小高度 650px；更小视口允许页面溢出，不提供移动端布局。手机配对是保留的独立原生能力，不代表此次原型要做移动端站点。

## 5. 能力保留与页面映射

| 既有能力 | 原型入口 | 正式改造要求 |
| --- | --- | --- |
| 通用 Agent、会话与历史 | Agent 会话、会话历史 | 复用会话标识、存储与恢复，保留完整原会话操作 |
| 流式输出、工具执行、停止和权限确认 | 会话消息、步骤、停止、确认交付 | 真正状态来自 runtime；不能把前端计时器当执行状态 |
| 官方及第三方模型、凭据 | 设置 → 模型与服务、会话选择模型 | 沿用原有凭据管理；不把密钥放到前端存储 |
| 本地工作区与原生目录选择 | 侧栏置顶工作区、设置、资料页 | 继续通过宿主原生选择器和权限体系访问文件 |
| 自建与社区工作台 | 企业工作台 → 市场/创建 | 保留社区与自建空间，不仅剩企业预设 |
| Agent Preset 导入导出 | Agent 中心 | 保留 `.dshpreset` 包格式、冲突检查、信任提示 |
| 插件搜索、安装、更新、卸载、配置 | 插件与能力 → 市场/配置 | 接回原插件管理完整页面；静态原型未重做市场 |
| Skills、MCP 与工具组合 | Agent 配置、插件与能力 | 保留高级配置；企业策略在其外部增加约束 |
| PPT 模式、16 套模板、可编辑 PPTX | 会话 → PPT、品牌演示工坊 | 使用原来的模板选择与生成流程；原型只画 3 个样式 |
| Python/Office、DOCX/XLSX/PPTX | 文档工作台、交付预览、办公插件 | 保留资源准备、文件生成与预览链路 |
| 图像生成、网页检索、终端 | 插件与能力 | 保留对应服务与配置；可见入口不等于已经连接服务 |
| 团队、语音、自动化等实验能力 | 插件与能力 → 实验性 | 保留实验性标记与依赖准备要求 |
| 手机局域网/临时公网配对 | 设置 → 手机连接 | 保留二维码、密码、断开和回退机制；企业可设策略 |
| 更新、跳过版本、用户确认安装 | 设置 → 更新与恢复 | 保留原更新流程；企业发布渠道另行决定 |
| 安全模式、故障恢复、日志、重启 | 设置 → 更新与恢复 | 保留启动失败时独立可用的恢复入口 |
| 主题、缩放、原生窗口与菜单 | 设置 → 主题、顶部标题栏 | 保留原快捷键、编辑菜单与窗口操作；不是只保留画面 |
| Profile/插件/会话/配置跨升级保存 | 设计约束，非独立页面 | 不更改或清空原数据目录；制定迁移与回滚策略 |
| 本地优先、隔离与隐私配置 | 设置 → 隐私与数据 | 保持 renderer 隔离、安全机制与联网透明性 |

企业可增加默认配置、推荐能力与权限策略，但禁止通过换皮删除原有功能。没有在原型中深入绘制的原生配置页，应通过“高级配置/原有设置”接回，不能默认为取消。

## 6. 拟新增企业能力

以下均属于设计提议，尚未接入或实现：组织与成员、部门可见性、集中策略、共享知识检索与引用、资料发布与版本、审计用量、企业品牌和模板管理、ERP/CRM 等系统连接。

共享知识库需要确定索引、更新、授权和引用定位方案；本地文件列表不等于知识库。成员权限需要受信任的服务端或宿主执行校验；单个本地客户端的 UI 角色切换不能保证企业权限。业务金额和写入规则应由确定性业务工具校验，不交给模型自由决定。

产品结构预留“本地单机企业定制”和“企业集中管理”两种发展方向，本轮不假定已有后端、SSO 或多租户。正式选型前需确定企业是否允许调用云模型、是否需要多人共享以及管理服务部署位置。

## 7. 可演示交互

1. 首页点击销售经营分析，进入销售周报任务。
2. 阅读执行步骤、资料与目标文件，点击预览检查报告。
3. 点击确认交付，任务状态更新为已完成；或退回修改，补充要求。
4. 下载得到标明“原型演示”的 `.txt`，不冒充 DOCX/PPTX 文件。
5. 在会话输入要求后发送，模拟短暂执行；可在完成前停止。
6. 点击附件，使用浏览器文件选择器；只显示文件名，不读取内容、不上传。
7. 企业工作台可分类、搜索，并通过表单添加本次会话的演示卡片。
8. 任务中心支持状态筛选；资料页支持分类；插件页支持分类和演示开关。
9. `Ctrl+K` 或顶部搜索可查找页面、工作台和资料；弹窗可按 Esc 关闭。
10. 企业管理修改企业名与应用名，尝试保存到浏览器 localStorage；其余状态刷新后重置。
11. PPT 模板、Preset 导入预检、模型配置、角色、手机连接和恢复入口提供说明或演示弹窗。

可真实发生的动作仅限浏览器内导航、演示状态变化、本地品牌偏好、读取用户所选文件名、下载示例文本或 JSON。不会请求模型、发送邀请、安装插件、打开隧道、处理真实 Office 内容或写入业务系统。JSON 配置示例不是 `.dshpreset` 包，不能直接导入真实应用。原型不收集 API Key。

## 8. 后续实现建议与验收

先确认品牌与导航、工作台业务分类、首页信息优先级；再明确单机/共享需求和首个真实业务流程。正式开发需要遵守 Fork 的 AGENTS.md 与 Patch/Plugin 规范，先核对现有 slot 和宿主插件接缝。HTML 原型只是产品交互参考，正式 UI 应在原 React/Harness 体系内实现，而不是另建业务前端取代原界面。

实施验收至少覆盖：已有会话可打开和恢复；模型与凭据可配置；工具可调用和取消；工作区可选择；附件与结果可预览；PPT 模板流程不回退为另一引擎；Preset 可导入导出；插件可安装配置与卸载；实验入口仍可达；手机连接可开关；更新与安全模式可恢复；旧数据跨升级保留。企业新增权限还应测试越权读取、写入和网络外发，而不能只检查页面按钮。

当前原型的生成结果和演示数据不得作为真实 Agent 运行验收依据。源码参考：`../dsh-desktop-fork/README.zh.md`、`../dsh-desktop-fork/src/shared/desktop-menu.ts` 与 `../dsh-desktop-fork/packages/`。


## 9. 十轮完善后的补充

工作台先显示三步业务流程和默认资料范围，确认后进入独立任务上下文。销售周报提供完整静态结果演示，其余业务展示真实的空状态与任务要求，不再复用销售结果。新任务快捷键为 `Alt+N`，全局搜索为 `Ctrl+K`，支持方向键选择搜索结果。
