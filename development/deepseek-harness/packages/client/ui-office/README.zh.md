# @deepseek-ai/dsh-client-ui-office

[English](README.md) | 中文

## 概述

本可选插件增加员工导航栏、工作台仪表板、日历列表、工作筛选、公司通讯录和个人资料编辑。员工可使用部署指定的本机身份，也可登录[集中办公服务](../../enterprise/office-gateway/README.zh.md)。原生会话、设置、工作区导航和插件管理仍由原来的插件负责。

Web 和桌面端共用办公样式。工作台分栏、统计列数和通讯录布局随可用面板宽度调整。窄屏网盘将目录树放在文件表格上方，命令栏可横向滚动，表格保留独立的横向滚动。办公控件继承已选字体，并适配键盘焦点、系统对比度模式和触摸点击区域。桌面标题栏间距沿用外壳的平台及全屏标记。

网盘可选图片、授权知识库和办公交付检查的配置、权限、保留及限制见[网盘读取参考](../../enterprise/office/drive-readers/README.zh.md)。

## 使用本包

在“身份与审计”中按来源、操作人、目标、精确操作名称和时间范围筛选组合元数据，再选择“应用筛选”。来源包含原审计类别及执行阶段、邀请、集中策略、群协作和真实用量。筛选时间使用本机时区，记录时间标明显示时区。“读取更早记录”继续当前查询；编辑筛选后须查询成功才能导出。无效输入会保留并提示修正，不发送请求。

“导出已显示记录”以每批最多 100 条重新授权全部已显示记录，并比对所有元数据字段后才生成一个 NDJSON 文件。记录变化要求重新查询；任一批失败均不产生部分下载，保留已审核记录供明确重试。下载派发前关窗或失去管理员权限会阻止文件保存；成功反馈在原浏览器文件保存器实际派发后显示。办公管理员可在聊天关闭时查询元数据，消息历史仍受原聊天授权约束。缺少协作 RPC 的旧 Host 仍显示不可用。

打开“通知 → 协作与通知”，使用统一接收者消息、群聊、通知偏好和有限重复会议。面板需要办公服务提供协作方法；旧 Host 会显示服务不可用提示及刷新入口，不会把不支持的操作标为成功。原日程、私聊、文件和登录仍由原功能管理。

群主须明确确认关闭群聊或向当前成员转交群主权限。发送前可以移除所选附件，切换面板页签会保留表单输入。未确认的消息或会议使用原请求标识和原内容重试；明确无效的消息输入允许修正。切换账号或服务端拒绝授权会清除私有表单，迟到结果不能恢复它们。已确认操作的反馈在关闭对话框后仍可见。

管理员可以检查全部角色范围，在保留管理员办公访问的前提下确认保存集中策略。并发策略变更会保留草稿，须明确“载入最新策略”。成员访问分别显示清理受阻、回收完成与已恢复：“继续清理”复用发起管理员的原请求；恢复要求成员已启用并明确保留哪些限制，且不恢复旧会话和邀请码。审计查询失败不会禁用策略管理。用量显示真实已报告计数和记录覆盖，缺失计数及费用保持未知。

配置的集中网关声明入职邀请能力后，管理员可在启用成员的密码管理中选择“入职邀请”。核对成员、角色及以本设备时区显示的明确有效期后签发邀请码。邀请码仅在当前对话框显示，点击复制才写入剪贴板，关闭即丢弃。签发结果不确定时使用原请求重试；已确认的重试只返回元数据，不能找回邀请码，交付丢失时需撤销后重新签发。撤销邀请码不会撤销已经设置的密码。

只有网关声明此能力时，未登录表单才显示“接受入职邀请”。接收人填写邀请码和两次一致的首次密码，随后使用返回的成员账号进入原有登录流程；激活不会创建登录会话。激活失败保留表单，结果不确定时提示先用所选密码尝试普通登录。邀请码和密码只存在于当前组件和表单控件，不进入共享快照。换账号、角色或目标权限变化、能力撤回会关闭对话框并隔离未完成结果。本地身份模式和旧网关保留原登录界面。[办公服务](../../enterprise/office/README.zh.md)定义邀请配置、适用成员、持久化与恢复。

办公历史访问策略同样约束工作区元数据：其他员工不能归档、停止、恢复、置顶、取消置顶或重排已归属的会话，也不能将其用作排序锚点。命令结果、跟随基线和排队增量会隐藏其 Session 标识。Session 作用域的文件查找、读取及监听帧，在访问与交付前复核同一可见性；读取期间更换员工后不交付其字节及元数据。检查不激活冷 Agent，也不修改 Session 记录。工作区目录仍由 Host 拥有；此筛选不建立企业文件系统租户隔离。

原生文件、终端、作业及 Changes 访问还要求员工当前角色与 Session 已认领角色一致。已打开请求保留最初的员工与角色限制，后续经过审核的新输入认领其他角色后，也不能给旧请求续权；新请求使用新认领的角色，普通员工历史仍可浏览。每次资源检查仍读取当前认证权限及原 Session 归属，请求快照只施加限制，不授予权限；未关联办公的原生 Session 保留原访问模型。

在集成页选择“联系产品公司定制”，或在工具页选择“定制企业技能”。填写系统或技能名称、联系人及需求说明后保存。“我的定制需求”可重新打开本人的已保存版本进行编辑。“导出已保存版本”在确认审核版本仍为当前版本后下载 JSON。未保存的修改和结果不确定的保存不可导出；可原样重试未确认保存，或明确加载发生冲突的最新版本。关闭表单会清除页面状态，但不会取消服务端已接受的保存。需求状态为“已保存，未发送”；请通过公司认可的渠道交付导出文件。仅在办公服务声明支持此能力时显示入口。

管理员从“个人资料 → 审计记录”进入，不增加左侧导航。可按来源、操作者编号、目标编号、操作名称及包含端点的本地起止时间筛选，行内时间使用 UTC。“请求拒绝”在操作名称旁展示已有的安全拒绝原因；旧记录保持原有呈现。查询先返回 20 条，“加载更多记录”明确追加更早记录。查询失败保留已显示记录，并提供重试。“下载已显示记录（NDJSON）”包含所有显示行及已加载的更早页面：Host 逐批重新授权，客户端核对其仍与显示元数据一致后，才创建一个文件。拒绝记录保留可选的 `denialCode`；字段缺失、变化或多出内容时阻止下载，包括被拒绝的请求正文和凭据。元数据变化或缺失时要求重新查询；请求失败不生成文件，保留已显示记录供重试。修改筛选立即清空旧结果；账号、角色、启用状态、退出、关闭及连接变化会丢弃未完成结果和下载。[办公服务](../../enterprise/office/README.zh.md#use-this-package)规定保留来源及审计限制。

搜索弹窗打开时聚焦查询框，关闭时将焦点返回到调用它的控件。初始焦点由共用 Modal 组件管理，使键盘和鼠标入口遵循相同的焦点周期。

全局搜索可从办公页标题栏打开。办公页面通过原会话搜索命令承接 Ctrl/Command+K，Web 也直接提供此全局键位。独立 `office.search` 命令在桌面端默认使用 Ctrl/Command+Alt+K，办公页面以外保留原生会话搜索的原快捷键。终端及其他弹窗保留各自输入权限。搜索有权查看的成员、日常及保留事项、私有／共享网盘元数据、当前会话技能和页面。空查询只列页面；每类最多发布 20 条，截断或部分目录失败会明确提示。方向键选择，Enter 打开，Esc 取消。事项进入当前工作范围，成员打开资料，文件进入授权目录并选中，技能只展示详情，不准备或发送请求。导航前重新核对目标；账号／角色变化、关闭及替代查询会丢弃过期结果。搜索通过现有元数据接口读取，不创建 Agent 或文件副本。

工作页提供日常工作、归档和回收站。任务／待办的发起人或管理员可在详情选择归档或删除，填写说明并确认；取消不写入，失败或竞争保留说明及已查看记录，直到明确加载最新版本。其他参与者可查看历史，但不能归档、删除或恢复。非活跃详情禁用日常工作操作，保留授权附件下载。恢复将相同记录放回日常工作，状态和分派不变；待验收交付须重新提交。删除会移入回收站，保留文件、原生会话和审计历史。

打开任务或待办后，选择“管理工作附件”，从私有或共享网盘目录选择最多 20 个已确认版本。新文件先在网盘上传。保存才提交引用；取消丢弃草稿，冲突保留草稿直到明确加载最新事项。关联资料按当前网盘权限读取文件名和下载，无效引用不显示缓存的私有文件名。关联不授权，文件分享须另在网盘设置。版本变化需重新选择，附件变更后重新提交交付。下载重试保持已确认版本，不会自动切换到替换版本。未提供附件能力的旧办公服务保留既有详情。

构建仓库后，使用 `pnpm run start:web --patch ./enterprise-workbench.patch.yml` 启用。[部署补丁](../../../enterprise-workbench.patch.yml)会开启办公服务、本插件及[原生办公工作工具](../../enterprise/tool-office/README.zh.md)；三者在默认 Web 组合中均关闭。示例公司有一名管理员和一名本机员工。请显式配置办公通讯录，并将本插件的 `principalId` 设置为该员工 id。通讯录种子仅在尚无已保存办公数据时使用；重启不会替换员工或事项。

办公模式延后自动凭据向导，使日历、任务和员工聊天在尚未配置模型时即可使用。预览版说明保留，模型设置仍提供原有服务商和凭据配置。使用 AI 会话前需配置企业模型。

导航顺序为工作台、AI 会话、通讯录、网盘、工作、集成、工具，底部为团队和设置。首页结合每日统计、周日期条、当日事项和 Agent 输入框。日历列表保留已完成及已取消事项。可以向启用成员新建任务或待办，也可以填写时间区间、地点、备注和邀请成员创建会议。事项详情允许有权限的用户更新状态。资料编辑只改变联系信息，不改变角色。

未关闭会议的主办人或管理员可在详情中选择“编辑日程”并勾选成员，主办人始终选中。新增成员收到邀请，被移除的普通成员失去日程读取权限并保留含此前标题的移除通知。仅改成员时保留原答复，修改日期或时间会要求受邀人重新答复。其他操作修改已查看的会议时，编辑器保留未保存字段和成员选择、禁用保存，并提供明确的“加载最新日程”操作。加载最新记录会同时替换字段与成员选择。保存新日期后，日历打开对应日期。已关闭日程禁用编辑。

新建和编辑日程会显示当前员工有权查看的办公日程中时间重叠的会议。提示按草稿日期、起止时间和选中成员重新计算。首尾相接的区间、已关闭会议、已拒绝的参与及正在编辑的日程不产生冲突。提示列出可见会议和受影响成员，不读取私人日历。提示仅供参考，其他成员可能另有私人安排；保存仍按原有权限和修订号检查执行。

待处理任务的当前负责人可在详情中选择“接受任务”或“拒绝任务”。负责人、发起人和管理员可将未关闭任务转交给其他启用成员。拒绝和转交需要填写原因，取消表单不产生写入。并发修改会保留输入，再次提交前须明确载入最新任务。任务操作记录跨刷新保留操作者、原因、时间和负责人变化。已关闭任务禁用这些操作，原有状态控制继续可用。原负责人仍可阅读转交通知的标题，但不再拥有任务读取权限。

“编辑事项”可修改未关闭任务或待办的标题、备注、日期和可选截止时间，清空时间会移除具体时刻。并发更新后，编辑器保留未保存输入，要求明确加载最新事项；取消不写入。保存保留负责人、生命周期和操作历史，并刷新选中日期。已关闭事项禁用编辑。失去事项读取权限时关闭编辑器并丢弃草稿，恢复权限后不会自动重开。

事项编辑器还可选择低、普通、高或紧急优先级。详情显示当前优先级，既有及新建事项默认为普通。非默认优先级显示在列表标记中，继续使用原有日期时间排序。优先级被并发修改时保留草稿，保存前须加载最新事项。

待办详情为当前负责人、发起人或管理员提供“转交待办”。表单要求选择其他启用成员并填写原因，说明待办将重新待处理。并发修改会保留输入，要求明确加载最新记录。转交历史保留操作者、前后负责人、原因和时间。已关闭待办禁用转交；既有状态和内容控制继续独立使用。

“工作”按本地日期分组展示任务和待办，有时间的事项排在前面。归属筛选入口显示状态筛选前的数量；“全部工作”仅包含 Host 授权可见的记录。会议仍在日历中查看。打开和关闭详情会保留工作筛选。日历支持输入日期、前后一天、周日期条和返回今天；到四位年份边界时停止越界导航，不再请求无效日期。选择“今天”后，每次刷新均按公司配置时区确定日期，包括打开通知和点击重试；手动选定的日期会持续保留，直到再次选择“今天”。

列表和详情按服务器的公司时间判断，为未完成事项显示“已逾期”，为会议显示“未开始”“进行中”或“已结束”。会议阶段不改变可编辑的已保存状态。“时间待核对”表示该项存档时间无法解释，其他事项继续可用。详情标明公司时区。标记随既有办公视图刷新更新，不依赖浏览器时钟或浏览器时区判断。旧服务器未提供可选时间投影时保留原有界面。[办公服务](../../enterprise/office/README.zh.md#use-this-package)定义截止、夏令时和已关闭事项规则；这些标记不创建提醒。

可见窗口每五秒重新验证办公身份，固定身份和集中网关部署均适用，包括首次读取失败后的恢复。登录等认证修改期间暂缓该周期刷新，周期业务刷新仅在已有已确认连接时发起。恢复时确认仍为同一员工及角色会保留已打开表单；身份或权限角色改变时清除私有缓存并重新读取有权办公视图。隐藏窗口暂停该周期操作，插件卸载时移除计时器。

“集成”展示公司实际登记的系统，可按名称、开发方、业务负责人或功能搜索。详情显示清单版本与登记状态。管理员选择文件或粘贴单个 JSON 对象，审核后确认登记；取消不写入。“导入说明”列出必填字段，并可下载可复用的 JSON 示例。服务端检查 256 KiB 上限、名称重复及当前管理员角色。失败保留已审核文本和重试标识。普通员工可以查看，但不能导入。清单登记、原生插件安装和连接测试保持各自的实际状态。

连接状态与目录分别读取。管理员为已登记系统配置获准的基础地址、相对检查路径、可用适配器和服务端凭据别名，密钥值不进入页面。保存保留审核版本，回执不确定时冻结原内容用于准确重试；其他窗口修改后保留表单，直到管理员显式读取并采用最新配置。详情提供受限时长的连接检查，展示检查时间及不同网络／认证结果，已完成检查不替换配置就绪状态。员工只接收就绪状态，不接收可编辑地址或凭据选项。换账号、失去管理员权限或卸载时释放私有配置并隔离迟到结果。[办公服务](../../enterprise/office/README.zh.md#company-connections)负责来源策略、凭据解析、探测上限及适配器释放，原生 MCP 和插件管理继续使用原有页面。

已声明的读取操作提供“同步”，先审核操作名称和已保存的连接版本。“读取并保存”访问客户系统并私有保存实际结果，取消不读取。保存结果不明时保留原请求供“重试原请求”；已确认的网络失败显示为失败记录，再次发起同步使用新请求。“同步历史”分页只列本人的元数据，选中记录后重新核对当前授权和连接，再显示带时间的历史字段。查看历史不访问客户系统。替换账号或角色、离开集成页以及卸载会关闭私有窗口；连接变化移除已显示字段，直到再次明确授权读取。不支持同步的旧服务器保留原查询入口。[服务文档](../../enterprise/office/README.zh.md#synchronized-read-records)说明存储上限与恢复约束。

“工具”按分类筛选、搜索和展示原生技能、办公任务模板及已登记公司系统的详情。原生目录通过现有会话技能接口读取当前员工最近选择的会话，包括事项协助会话，并遵循该会话的工作区、Agent 配置和调用策略。打开工具页不创建会话或模型请求。选择 AI 会话后可发现其技能；“刷新”在读取失败时重试并保留最近可用目录。“添加技能或插件”打开原生插件管理器；“添加系统工具”打开公司集成页面，可登记钉钉、企业微信、OA 等公司系统并展示实际连接就绪状态。

“填写使用要求”打开当前窗口表单。准备原生技能时再次检查其可用性，将明确调用及要求插入所选原生草稿的开头，保留已有文字、引用卡片和附件。任务模板插入文档、表格、演示、PDF、会议纪要、审批材料或提醒的普通请求。尚未选择会话时，模板会在当前或最近工作区准备全新的原生输入；缺少工作区或输入忙碌时保留表单以便重试。准备不会发送；员工审核原生输入并点击发送后，继续使用原有技能加载器、模型和持久会话日志。换账号、角色改变、取消及插件卸载会隔离未完成准备，关闭要求表单会丢弃其中的本地文字。模板不会安装技能或开通外部业务操作。

管理员可在“团队”添加、编辑、停用成员和分配账户角色。员工编号创建后不可修改，停用后也继续保留。重复创建以及基于过期成员资料的编辑会被拒绝，不覆盖现有数据。资料发生变化时保留表单草稿，直到管理员主动加载最新信息。最后一名启用的管理员不能降级或停用。停用成员保留在管理员通讯录中，并从普通通讯录和派发选项中移除。普通员工不会收到管理控件或停用成员资料。

点击成员姓名可查看其当前部门、岗位、账号角色、邮箱和电话。已配置正式组织时显示正式归属，成员详情只读。消息、任务、日程和待办操作会预选该成员，打开操作时关闭详情并保留通讯录搜索。成员从有权通讯录移除时关闭详情，再次启用不会自动重开。头像首字保留完整 Unicode 码点，包括补充平面字符。个人资料编辑保留服务端管理的账户角色。

“通知”显示当前员工的收件箱和未读数量。打开通知会先持久化已读状态，再打开有权查看的事项。受邀人可在详情中接受或拒绝邀请，不会修改整场会议的状态；已关闭会议不再接受答复。每次操作都重新检查 Host 分配的身份和已查看的事项修订号。写入失败保留对话框并显示本地化错误。浏览器验收覆盖受信任 Host 发起方及浏览器接收方，检查发起方通知和持久化已读状态。

公司启用中央提醒后，同一收件箱会显示已到期工作和已开始会议。提醒行使用当前有权查看的标题，不显示虚构发送人。全部／未读筛选和未读角标包含这些投递；打开未读提醒时，先等待持久已读确认，再打开有权查看的事项。确认失败保留原行供重试，已读提醒再次打开不产生写入。服务器变更刷新当前选定的日历日期，集中网关继续使用已有可见窗口周期刷新。事项完成、取消、转派或失去权限后，对应旧提醒会在刷新时移除。旧服务器和未配置提醒的部署保留原收件箱。[办公服务](../../enterprise/office/README.zh.md)定义投递窗口、去重和保留容量。

“发消息”打开员工私聊，提供会话/联系人列表、头像和左右气泡。工具栏位于输入框上方，可插入表情并派发任务、会议或待办，自动预选当前联系人。Enter 或 Ctrl+Enter 发送，Shift+Enter 换行，中文输入法组合期间不提交。已确认消息和已读回执在重启后保留。更早消息按游标加载；停留底部时跟随新消息，查看旧记录时保持阅读位置。各联系人草稿在办公页面、嵌套表单和聊天关闭重开之间独立保留。发送完成只清除 Host 确认的原文本，不清除请求期间新输入的内容。更换身份会清除私有缓存和草稿，并忽略上一员工的迟到响应。

本窗口已有可用的普通输入时，首页嵌入原生 Conversation 内容，与独立页使用同一个编辑器、附件、引用、模型控件及输入接管界面。在任一页面编辑都会修改同一份输入；本窗口明确的原生提交会打开对应独立会话并只提交一次。“展开会话”只打开，不发送。原生引用通过资源作用域跟随员工生命周期；办公状态快照只包含输入标识。其他窗口不会替换本窗口已经选定的普通输入。

尚无普通输入时，首页保留初始文字和浏览器文件选择，通过 `uiWorkspace.startPreparedSession` 准备。发送或 Ctrl+Enter 准备后只提交一次；展开接纳草稿而不发送。文字与附件均为空时不发送。准备失败和取消时保留原选择供重试，成功接纳仅清除已提交的首页文字。接纳后，上传及后续失败沿用原生控件和所有权。工作区需通过原生选择器准备。“原生工作区”展开原侧栏，“设置”打开原设置；卸载插件恢复原生导航。

<a id="understand-the-implementation"></a>

“让 Agent 协助”先重新读取员工有权查看的事项，再按账号与事项关联独立原生会话。首次打开填入上下文而不发送，再次打开保留原会话的草稿和历史。附加上下文卡可返回原办公页面、选定日期和筛选。当前窗口的独立引用让原生附件草稿在事项间切换时保留，退出账号或卸载插件时释放。事项更新会提示核对，不改写已有草稿或历史提示词。关联资料当前显示空状态。

会话标题栏在首条消息前也提供个人资料和会话列表。列表通过原生右侧页签注册器扩展，新建会话沿用原生工作区创建，搜索筛选原生标题、当前有权事项名称及工作区路径。归档会话和子 Agent 保留原入口。首次进入且窗口至少 1040px、未记录其他资源页签时自动打开列表。自动打开的列表在窗口小于 1040px 时收起，包括从办公页面返回时，页签和搜索仍保留。本窗口内手动通过标题栏打开的列表，以及包含其他资源页签的布局，继续遵循原生展示方式。文件、终端、浏览器及交付物继续使用各自原生页签和配置，内置浏览器保留原有的显式启用设置。

AI会话入口和首页“展开会话”返回本窗口最近的普通会话，与事项协助分开。冷启动窗口读取已提交的返回目标，不改写原生历史。普通／事项会话切换时，原生文字与所选文件草稿独立保留；账号变更取消待完成导航，并释放普通输入资源。浏览器本地记录保存返回目标，并在此列表隐藏其他员工已记录的办公会话；尚未分类的 Host 历史仍可通过原生入口使用。完整多用户原生执行隔离仍待完成。这项导航便利不构成多用户 Agent 授权边界。

浏览器私有数据库 `dsh.office.conversations.v2` 使用数据库版本 1，在 `navigation` 存储区保存带格式版本的记录。每次更新在同一个 IndexedDB 读写事务内读取并合并当前记录；多窗口重叠写入依次提交，归属仅在提交完成后发布。localStorage 中的修订号通知触发重新读取数据库，不切换到另一窗口选中的输入。通知失败时提示保存已成功，但需要刷新同步。无效或被外部改写的归属、缺失记录和不支持的版本会停止依赖它的导航，不重置数据，也不释放最近验证过的原生输入。写入失败不发布新归属；“刷新会话”可重新加载并重试登记当前输入。

首次创建数据库时，在同一个升级事务内导入已有的 `dsh.office.conversations.v1` localStorage 索引。旧记录的字节保持原样，后续读写仅使用数据库。旧数据格式错误会使初始化中止，不会被替换为空索引。该格式只包含会话标识和员工归属，不保存提示词、文件句柄或原生历史。清除全部浏览器站点数据会删除这些本地导航记录；原生会话日志继续由原有模块管理，格式不变。

会话输入区提供“关联集成”“关联工具”、搜索、多选、详情及取消关联。已保存选择归属当前员工和实际原生会话，事项会话独立保存。工具准备先确认对应技能或模板的关联，再接纳待发送输入；准备失败保留使用要求表单。工具声明的依赖会加入已登记公司系统，缺失登记、显式移除的依赖及连接就绪状态分别显示。后台刷新保留表单审核版本，竞争修改要求显式采用最新选择，保存结果不明时冻结原请求供准确重试。确认后的选择在刷新和服务重启后保留；编辑选择不改写原生 Session 历史。

已有保存关联时，明确的原生发送会在收件箱接纳前捕获审核选择及系统描述元数据。捕获文字成为独立的原生上下文记录及模型输入，后续关联编辑不会替换本次提交的快照。打开“轨迹”并选择对应“上下文”行，可检查已提交快照；聊天保留原有的普通上下文隐藏规则。清空选择后，后续发送会记录明确的空快照。从未保存关联的提示词保留原来源结构。准备失败会阻止接纳；审核选择改变后，重试先前未接纳的请求可能需要重新提交。确认退出办公登录后，受信任 Host 仍保留原有原生能力。快照不授予业务执行权限，也不暴露连接地址、凭据别名或秘密值。

明确点击 AI 会话或首页空白“展开会话”时，会等待员工视图及原生会话、工作区目录首次就绪。尚未返回的空目录不会触发新建。AI 入口会标记等待状态；切换办公页面、调用方取消、身份替换或插件卸载都会取消这次进入意图。就绪后，明确的进入请求会取代尚未完成的原生启动导航，恢复已保存的普通输入。原生文字、所选文件和事项草稿仍由原模块管理。

### 员工聊天中的文件

输入框上方工具栏的文件按钮为当前联系人选择受限的私有文件。切换联系人、打开任务／日程／待办表单或关闭聊天时，各联系人保留自己的文件选择。可在发送前移除文件，也可不填说明直接发送。页面显示服务端的合计字节与文件数量上限，默认每条消息最多五个文件、合计 8 MiB；该策略及额度与网盘分开。文件消息展示不可变元数据和授权下载按钮，成员停用后的历史会话也可使用。

确认发送只清除原文件选择及相同文本，账号在等待确认前捕获。发送期间锁定该联系人的文件选择。下载在浏览器保存前核对消息／文件标识、元数据、大小和 SHA-256。更换身份或卸载会丢弃私有句柄及重试内容，阻止迟到读取或下载上传、保存文件或清除另一位员工的输入。Hook 快照只含 JSON 元数据及状态。无法读取文件策略时，输入框仍可发送文字并提供重试。

支持持久草稿的服务端会自动保存每位联系人的私有文件选择。“文件已保存”确认刷新恢复，未确认编辑仍只保留当前窗口。恢复元数据不会下载全部字节，发送恢复选择使用服务端审核版本。保存失败保留文件及原重试标识；其他窗口修改时，必须明确选择“保留当前文件”或“加载已保存文件”，不会自动覆盖。未确认发送保留原说明及 UUID，“重试原文件发送”保留之后新输入的文字。“清除文件草稿”只处理审核过的选择，停用联系人也可使用，已发送消息保持原样。“聊天记录”可打开本人的会话或保留文件草稿，即使联系人已停用。旧网关继续使用当前窗口的文件流程，并明确要求刷新或退出登录后重新选择。

办公服务端声明目录支持后，系统详情提供“查看业务动作”。当前员工显式读取或刷新提供方按角色允许的动作名称、说明及读写类型。连接不可用时显示实际状态并清除旧目录。换账号、角色变更、竞争读取、显式刷新连接及卸载都会拦截迟到结果。查看目录不探测连接，也不执行业务操作。旧服务端保留原详情页面，不发起不支持的请求。

可执行的读取声明提供“立即查询”。服务端使用审核过的连接和提供方版本，为当前员工查询已登记系统。结果以纯文本概要及字段显示在有界滚动区域。重试失败会清除旧字段；认证、限流、超时及响应错误保留各自含义。身份、角色、目录或连接就绪状态变化会清除私有结果并拦截未完成的读取。查询不调用写动作、不创建模型请求，也不自动重试。结果仅暂存，刷新页面后消失；客户写操作及原生 Agent 查询仍属于后续工作。

公司明确开启[内部会议忙闲共享](../../enterprise/office/README.zh.md#use-this-package)后，新建和编辑日程表单提供“查询成员忙闲”。结果仅显示同事的布尔占用和查询时间；草稿、已查看的办公修订号或身份变化会清除结果，旧查询的迟到响应不能覆盖新结果。查询失败会移除旧结果并允许重试。提示仅覆盖内部会议，不预留时间或阻止保存。

事项详情向发起人、当前负责人和管理员提供“管理子任务”。草稿支持新增、改名、勾选完成和移除子项，再一并保存；取消不写入。发生竞争时保留草稿，并要求明确加载最新事项；身份或访问权限变化会丢弃草稿。详情显示子项状态和进度。已关闭事项禁用编辑，清单完成不会改变父事项状态。子项沿用父事项访问权限，不形成独立委派。

任务详情提供“交付与验收”。负责人接受任务并进入进行中后提交交付，发起人或管理员确认或退回，每次操作须填写说明。竞争变更会保留草稿并要求明确加载最新事项，取消不写入。提交后事项变化须重新提交；确认后任务完成并保留历史。进入此流程的任务不能通过普通状态选择跳过确认，没有交付历史的任务继续使用原状态操作。

### 本机集成插件包

集成页的“查看插件状态”从当前 Host 的原有插件管理器读取部署关联的包，分别显示安装、保存的启用选择，以及实际运行、等待或失败的组件数。“管理插件”直达原包详情，继续使用配置、启停和卸载。“审核安装”打开原表单并建议包名；检查、信任提示、脚本审批和取消保持既有行为。官方包沿用原更新流程，其他包通过卸载后重装升级。登记或查看页面不会安装代码。

在本机部署补丁中将连接器标识关联到 npm 包根名称。条目配置会替换下层值，因此同时保留已分配的员工身份：

```yaml
- id: ui-office
  config:
    principalId: local
    connectorPackages:
      company-oa: '@company/office-oa'
```

映射最多接受 100 个包根名称，不接受版本、模块子路径、URL 或文件路径，不增加依赖或执行权限。连接详情单独显示办公服务是否已注册连接器。网关模式说明公司适配器属于集中服务端，不为该服务端提供本机包操作。缺少配置管理能力时显示不可用，不把未检查的包报告为未安装。[插件管理文档](../ui-plugin-manager/README.zh.md)拥有包操作与依赖恢复约束。

### 场景与企业外观

场景与助手需要 Host 的办公配置服务。配置尚未载入时，场景入口保持禁用，失败后可选择**重试**。场景在所选已安装 Preset 下准备独立原生会话和待发送草稿，沿用其模型、工具与审批。导入助手会创建新身份；读取文件起即占用操作，保存和刷新完成后释放，退出登录会撤回尚未提交的读取。

在**企业外观**中，助手保存或明确重新载入不会丢弃尚未保存的外观编辑。如果其他窗口修改了外观本身，编辑器保留草稿并禁止**保存**；请先复制所需内容，再选择**载入最新设置**替换草稿。局部预览显示所选品牌、办公主题和密度，不保存配置，也不改变原生主题偏好。**恢复已保存设置**只丢弃本表单草稿，并将焦点送回企业名称；**保存**通过 Host 提交，失败保留草稿。手机地址无效或仅本机可访问时，字段会在提交前说明原因。配置 HTTPS 地址不提供手机配对或中继；桌面维护继续使用本仓库的原生桥和连接服务。

保存回复不确定，或保存已确认但配置列表未刷新时，编辑器保留草稿并阻止继续修改已保存配置。**核对已保存配置**只读取现有服务，不补发写入；核对失败继续保留草稿和禁用状态。核对成功后关闭旧助手草稿并聚焦已保存列表标题，或载入已保存外观；请先复制需要保留的编辑内容。无关的外观草稿不会被清空；此流程不提供跨客户端或传输层的请求幂等保证。

## 理解实现

组合包移除并停止其插件后，在同路径重装变化后的包版本会加载该版本的代码。覆盖已安装包、重新指向链接，或不修改版本就替换代码时，仍须遵循既有重启要求。[包管理文档](../../boot/plugin-manager/README.zh.md#reinstalled-package-code)拥有这些生命周期约束。

停止生成在取消在线 Agent 前检查当前员工对办公 Session 的可见性。其他员工或退出状态不能停止该运行。有权取消会保留挂起的后续输入，未关联办公的 Native 取消和子代理路由限制继续保留原有行为。

原生提示词在恢复 Agent 或确认此前已准入的请求前检查员工归属。其他员工或退出状态收到 `session/not-found`，冷态拒绝不激活 Agent；身份检查还覆盖图片排队准入和已准备输入。当前员工和未关联办公的 Native 会话保留不重复写入消息的幂等重试。

原生分叉操作通过 [Session Controller](../../api/session-controller/README.zh.md) 检查当前员工能否读取源历史。其他员工或退出状态不能复制具有办公归属的历史，冷源同样受限。成功分叉保留源日志中的员工限制；未关联办公的 Native 历史保持原有分叉行为。

办公首页或办公 AI 提交在原生发送前确认员工身份，即使未选择系统、技能或文件。准备会保留已有选择，或初始化空白的第一版选择记录；账号变化和取消使批准失效。员工 Host 的 `prepareNativeInput` 限制也拦截首个原生请求到达前的账号切换。提供方通过现有办公快照记录归属，并在首条输入接纳前复查身份。原生工作区的发送不初始化办公归属，启用覆盖层不会认领既有原生历史。这些限制不授予工具或数据权限。

原生队列编辑、移除和转向在解析 Agent 前及改变输入前检查办公归属。切换账号或退出后保留队列内容、消息标识和文件凭据，冷态拒绝不激活 Agent。当前员工继续维护待发送输入，未关联办公的原生队列及可继续子代理控制保持既有行为。

原生模型选择在解析前、等待准入后及模型配置解析后，要求当前员工继续有权访问具有归属的办公会话。切换账号或退出会拒绝选择，不追加事件或发起默认保存。冷态拒绝不激活 Agent。当前员工及未关联办公的原生会话保留模型和推理等级控制，包括后台保存默认值的行为。

原生改名在解析 Agent 前及追加标题前分别核对当前员工。其他员工或退出登录后，对具有归属的办公会话返回 `session/not-found`，冷会话同样适用。跨账号切换的迟到请求不能追加标题。当前员工及未关联办公的原生会话保留改名能力。其他原生修改操作仍需各自完善授权。

原生 `session.attachment` 接口在读取图片前及交付字节前核对同一可见性。切换员工或退出会阻止读取具有归属的办公图片，进行中的读取同样适用。冷读取不激活 Agent，也不改写图片或 Session。当前员工及未关联办公的原生会话保留图片访问能力。原始 Host 文件路由继续采用受信操作者范围；这些检查尚不构成共享多用户 Host 隔离。

员工 BFF 独立于办公工具插件维护 Native 归属及读取策略。原生查询与投影服务存在时，它注册共享 Host 折叠状态，并按已认证且启用的员工核对历史页、当前格式投影及每个 follow 帧。其他员工收到 `session/not-found`，缺少所需状态时拒绝交付。冷检查通过异步观察显式请求 `officeRunOwnership`，不激活 Agent，也不向 Client wire 暴露 Host 状态。卸载办公工具保留身份服务、读取检查和当前历史流。办公提示词准备在生成贡献前及准备完成时复查同一可见性。其他员工或退出登录会使新输入在进入收件箱前以 `session/not-found` 被拒绝；既有未关联原生历史保留原行为。这不替代原生模型／工具守卫，不改变已接受请求的重试，也不阻止此前的 Agent 解析或附件暂存。读取归属不授予执行权限。列表省略其他员工的归属摘要；搜索先筛选候选范围，再在交付前复查摘要，隐藏匹配不占用授权结果限额。每次可见性检查在收集归属状态后核对启用员工；枚举期间消失的候选被移除，意外失败则拒绝整个响应。未关联历史及办公功能之前的迁移提示保留 Native 行为。Native 控制流对连接投影基线及后续每个替换帧应用同一可见性策略，包括身份变更后的缓冲帧。隐藏帧被略过，其他原生更新继续交付。普通 `api-session/added` 通知在离开转发队列时也会检查可见性；其他员工不会收到具有归属的摘要，包括先前登录期间缓冲的生命周期更新。其他 Native API、其余转发事件及共享多用户 Host 仍需独立授权。

同一历史授权保护 Session 作用域的工作区文件预览、保留的终端元数据、原生后台 job 及文件变更记录。文件读取在查找 header 前及交付字节或元数据前核验。终端列表和窗口持有不激活 Agent，跟随者检查每条快照、输出及状态帧。Job 列表、输出帧和 Remote 取消也按 Session 归属核验当前员工。变更摘要及对比的 HTTP 读取在查找前及交付 JSON 前再次核验。更换员工会抑制后续披露；已登记的策略撤回后，取消已持有观察并保持不可用直到替换项登记。拒绝终端或 job 跟随者不会终止其生产者；拒绝变更读取会保留原有记录。这些检查保留未关联办公的原生访问，不按员工划分 Host 文件系统或操作系统账号。

办公服务声明支持提交资料时，原生发送也会准备当前员工已审核的网盘引用。归属为 `office-files` 的快照冻结员工、角色、请求及不可变元数据，不把文件字节复制到原生上传。身份、角色或审核版本变化会使准备在接纳前失败。可选的原生办公文件工具按当前权限读取所选版本，并记录实际结果。未声明此能力的旧服务保留普通提交流程。

网盘的“用于 AI 会话”把当前有权访问的文本版本，或服务端分别声明的 `conversationFiles.pdf.maxBytes`／`conversationFiles.docx.maxBytes`／`conversationFiles.xlsx.maxBytes`／`conversationFiles.pptx.maxBytes` 上限内的 PDF／DOCX／XLSX／PPTX，关联到所选输入；尚无输入时在当前或最近工作区准备未发送的输入。各项可选能力独立启用对应格式，不提供这些能力的旧服务继续只允许选择文本。已有原生文字、内联引用和附件保留原有所有权。“关联资料”为准确的当前输入打开网盘；首页和独立输入显示同一份引用，并提供移除、明确清空、刷新及保存确认不明后的准确重试。员工、角色或实际所选会话变化会取消旧准备；初始化时持续没有选择，不会取消首个输入的分配。办公调用保留原有载体生命周期，取消准备会阻止迟到结果，不会回滚已受理的元数据写入。

已提交 PDF 引用通过 `office_read_pdf` 读取明确指定一页的真实可选文本；`office_read_docx` 读取 Word 正文段落／表格单元格，`office_read_xlsx` 读取保存的电子表格单元格，保留数字／日期原始词面并明确公式缓存状态；显式启用的 `office_read_pptx` 按演示文稿关系顺序，读取明确选择的一页正文或演讲者备注。备注不会自动附加到正文。[办公服务](../../enterprise/office/README.zh.md#prepared-contexts)拥有解析范围、worker 及完整结果上限；[原生办公工具](../../enterprise/tool-office/README.zh.md#execution)保留人工读取审批，并在下一次模型请求前记录准确结果。仅供 Host 使用的读取方法将原生取消传到本地解析器或认证网关。不把完整文档复制到原生附件或浏览器缓存。公式重算、PDF 页预览、图片理解、其他 Office 格式及 OCR 属于独立能力。

认证网关结果只向发起请求时仍保持原登录状态的 Host 返回。退出、替换账号或卸载后，迟到的成功响应及其中的私有文件正文不再披露。账号变化前写入可能已经提交，重试前应回到原账号恢复或核查结果。

服务端声明 `executionHistory.checks` 时，未知回执提供**核查客户处理结果**，按原标识读取已有操作，不重新提交业务值。UI 展示持久权威结果、仍未知、能力不可用或原连接已变。失败或过期的核查保留先前未知证据，账号／角色／系统／详情变化会拦截晚到结果。客户插件不支持时明确说明，旧服务器不显示核查动作。此核查不向原生模型历史添加消息。

已安装的声明业务写入提供自动生成的文本字段及独立确认前审核。发送前核查必填和长度，值保留准确空白及换行。首次发送后，不允许在保留的重试 UUID 下修改审核内容。响应丢失时提供明确的原请求重试，不创建新操作；已返回的未知回执改为提供执行历史入口。明确未接纳与权威成功分别展示。配置变化使审核失效；身份／角色变化及插件销毁清除私有草稿并拦截晚到回执。待处理表单等待请求结束后才能关闭，关闭不会回滚客户副作用。

在公司系统详情中选择**执行记录**，可浏览当前员工自己的业务提交。声明 `executionHistory` 的服务器提供由新到旧的小型元数据页，更早记录仅在明确操作后加载。选择回执后，单独读取有上限的业务结果及审计阶段。未知结果保留执行标识，明确要求再次提交前先核查。查看、刷新及分页不会调用业务写入器。加载更早记录期间完成的核查会保留最新展示状态和版本，不被晚到分页覆盖。状态模型在新读取前清除私有详情，并在账号、角色、系统、关闭、连接重置或插件生命周期变化后拦截晚到响应。旧服务器不显示此历史入口。

首页在日历下方展示公司公告，轮换当前获准查看的发布记录，悬停、焦点停留、页面隐藏或启用减少动态效果时暂停；用户还可切换前后公告及手动暂停。点击或 Enter 打开纯文本全文，查看发布人、时间和投递范围。管理员可管理公告、发布前核对接收人并确认撤回；发布失败保留表单和重试 UUID。事项通知与公告投递共用全部/未读收件箱及未读角标；打开未读投递时先等待持久已读确认，确认失败保留未读行供重试。旧服务器缺少可选公告视图时显示暂不可用。

管理员的团队页面提供首次配置、部门层级、限定部门的岗位，以及带版本的成员归属表单。显式配置前，通讯录继续使用原部门标签；配置后可按部门及下属部门筛选，搜索使用正式名称，头像和资料显示正式岗位。个人资料中的部门、岗位变为只读，联系资料编辑保留原成员字段，不能改变员工归属。并发组织编辑保留表单草稿，要求载入最新记录后再提交。管理员可维护停用历史，员工仅收到有权读取的启用层级。组织操作同时支持本机服务和集中网关。

网盘提供私有／共享文件夹导航、面包屑、已确认的前进后退、按权限过滤的名称查询、排序、键盘打开／重命名及适应窗口的右键菜单。文件夹创建、改名和所有者管理的共享账号条件使用办公 Remote。选择上传文件后先打开确认表单，取消确认不会开始写入。页面显示服务端当前单文件上限，受支持文本可以作为不可变引用关联到 AI 输入。网盘文件发送到员工聊天继续待办。

选择文件后，可从工具栏或右键菜单打开版本历史。“上传新版本”先选择源文件，再单独审核；所选源文件名称不同时，原逻辑文件名仍保持不变。取消不会开始上传。记录变化时需明确加载当前元数据，所选源文件继续保留。接受上传后，由传输面板持有原文件、审核目标和重试声明；发布失败可准确重试同一次操作。历史下载明确选择版本，重试仍保持该选择。既有工作附件下载保留当前头版本检查。账号或角色变化会释放保留的句柄，并抑制迟到的浏览器保存。

移入回收站时需按所选记录和当前父目录权限确认。回收站列出本人的可恢复删除根条目，不改变文件夹导航。恢复允许改名解决同级冲突；失败及竞争保留名称和审核版本。“刷新”和“加载最新记录”用于明确采纳当前元数据。失去当前访问权时禁用确认，并隐藏不可用元数据；认证失效会关闭私有视图。删除保留文件、版本及其额度占用。

“永久清理”审核完全属于本人的准确文件／文件夹／版本范围及字节总数。加载新范围后须重新勾选确认；取消不写入。确认结果未知时保留同一请求重试；“查询清理状态”先读取既有回执，再提供新范围。已获准但待完成的清理不能恢复且继续占用额度；“继续已获准的清理”沿用该回执。完成后释放对应字节额度，并从回收站移除根记录。页脚显示员工已用、上传预留及总额度。清理作用于网盘副本，保留原始 Native 会话交付物及历史。

当前目录失去编辑权限时，已打开的新建文件夹和重命名表单保留草稿，显示只读状态，并停止提交，直到当前权限重新允许操作；服务端仍在提交时再次检查权限。非法名称、同目录重名和写入失败均保留输入，不发布元数据。并发改名需要明确加载最新记录。名称使用兼容 Windows 的规则、NFC 规范化及不区分大小写的同目录唯一性，不同文件夹和私有网盘员工各自独立命名。

服务端声明分块传输能力时，双击或 Enter 可预览支持的 UTF-8 文本和位图，工具栏及右键菜单仍保留下载操作。HTML 等文本只显示源码。预览上限为文本 1 MiB、位图 8 MiB；不支持的格式和更大文件可下载查看。每块内容均按已选的不可变版本重新授权并校验 SHA-256，显示前再次确认权限及版本，空文件也执行此检查。打开的预览每五秒重新确认权限，拒绝访问或版本变化时撤下内容。关闭、切换账号、离开网盘或卸载都会丢弃预览字节和图片 URL，不写入浏览器持久化存储或会话日志。不声明分块能力的旧服务器继续使用原下载流程。

服务端声明可续传能力后，页面增量检查文件并按块上传。传输面板显示已确认进度、失败重试及取消；取消失败时保留独立的重试取消操作。响应丢失不改变重试声明。首次票据未返回时，取消会先查询员工本人的未完成声明。若没有匹配记录，页面显示已停止传输；可能迟到的预留仍由服务端过期策略处理，也可刷新查找。刷新后，未完成上传要求重新选择原文件，完整摘要匹配后才续传缺少的分块。下载按不可变版本逐段重新授权，分段及完整摘要均通过后才交给浏览器保存。取消及切换账号会阻止迟到响应保存内容。文件句柄和字节由所属对象私有持有，只有 JSON 进度进入 hook。旧服务继续使用 8 MiB 整请求流程。浏览器在创建 Blob 前保留完整下载内容，尚不支持直接流式写入选定的磁盘文件。

Host 的 `OfficeController` 提供 `office` Remote 命名空间。本机 `principalId` 和集中 `gatewayUrl` 必须且只能配置一种。集中模式由 Host 凭据提供者保存令牌，由服务端确定员工身份；浏览器不能指定业务操作者。业务拒绝返回稳定错误码，存储或传输异常保留为失败。员工 Host 继续保留原生 Agent 能力，集中网关只开放办公操作。

集中部署时，在标准 Web/Desktop bundle 后应用以下员工端覆盖配置，使用网关实际的 HTTPS URL；本机部署可使用回环 HTTP：

```yaml
- id: enterprise-office
  disabled: true
- id: ui-office
  disabled: false
  config:
    principalId: ''
    gatewayUrl: https://office.example/
- id: ui-settings-models
  config:
    credentialOnboarding: false
```

登录表单接收管理员开通的员工编号和密码。“账号与安全”列出本人设备会话，可撤销会话、修改密码和退出当前登录。管理员在“团队”为启用员工设置密码。密码修改会撤销旧会话，要求重新登录。令牌留在原生凭据提供者中，密码不进入可观察快照或浏览器存储。集中页面可见时每五秒刷新。账号变更会在显示另一员工前清空私有办公数据、联系人草稿及未发送的首页提示；Host 的原生 Agent 历史仍按原有语义管理。

连接身份和已认证业务响应在返回后都要求 Host 的原凭据继续有效。登录、退出或会话续签替换了凭据时，旧连接检查返回未连接状态，并保留任何替代凭据。控制器卸载后不披露迟到的身份结果。

不依赖 React 的 `OfficeModel` 管理已确认的远端快照、修改准入和提示。读取代次检查忽略过期响应，销毁后忽略迟到结果，授权失败会清除敏感办公数据。Slot store 仅保存筛选、搜索和草稿。组件通过 slot 注册接收回调与 hook，不访问 Cordis 服务。

插件向 `main` 贡献 `office.*` 页面，在可选的 `shell.navigation` 提供导航栏，并向 `shell.overlay` 添加提示。通过 `slots.inject()` 跟随声明生命周期注册。重连和 `office/changed` 通知会重新读取授权视图。[浏览器验收](../../../apps/web/tests/enterprise-office.e2e.ts)使用真实发行组合、Remote 编解码和 JSON 存储，无需模型密钥。

### 原生能力验收

原生兼容验收同时启用办公覆盖层和默认外壳。浏览器覆盖 Chromium／WebKit 流式会话恢复与历史重开、队列编辑和两种停止方式、文件／会话引用、模型与推理等级选择、权限策略切换、手动确认，以及携图片附件的可继续子 Agent 中断和 FIFO 恢复。用例操作原生控件、服务与持久会话事件，办公导航保持存在。完整请求头和事件比较使用独立的 Windows PowerShell 记录，并独立保留预期文件字节。既有 POSIX 记录不变；确定性模型重放仍执行实际 Host 工具。

供应商设置、只写凭据、自定义端点、配置恢复、用户调用 Skills 和 Skill 结果卡也在两种外壳中验证。插件验收通过现有管理器操作配置、依赖、启停、移除及包源回退。包源测试控制包管理器子进程，不代表已经从外部包源安装。MCP 验收启动真实本地 stdio 服务，通过原生会话执行工具，再停用和重新启用插件，检查历史与办公数据仍可访问。

原生自动化也在两种界面下验收：工作流运行／结束记录、子 Agent 导航及刷新恢复；After、浏览器本地 At、逾期 Every、每日规则、跨会话任务管理、送达记录、保留清理及删除。员工日历事项与这些 Agent 定时任务分别保存。Goal 栏的创建、用户暂停／恢复、解除运行和重复清除保持可用；办公会话通过真实 `get_goal`／`update_goal` 工具执行两个自主轮次，刷新恢复已完成记录。计划审核在切换办公页面时继续等待：批准后退出计划模式，请求修改则结束当前等待轮，由员工补充输入并继续计划模式；两条分支均保留计划材料供原生预览及刷新恢复。800×720 窗口下计划开关与模型控件保持可点击。首页提交会执行真实 `todo_write` 工具，刷新后恢复原生计划，且不创建员工工作事项。这些无密钥用例回放模型分块，同时执行真实 Host 服务。

原生工作区文件验收执行 `write`、`read`、`edit`，核对磁盘实际字节，并在缩窄窗口、刷新后恢复编辑过的 Markdown 预览。两种界面均验证沙箱 HTTP(S) 页面、应用已知历史和协议拒绝。Windows 验收启动真实 PowerShell PTY，检查工作目录与文件输出，收起、办公导航及浏览器刷新后保持同一进程，并确认关闭页签回收进程。终端准备提示是编写的测试记录，命令在真实受控进程中执行。原有 POSIX 终端用例分别保留，在 Windows 上跳过。

没有继承记录标记的旧子会话通过 `readOfficeRunAncestry` 核对保留父目录中准确匹配子标识和创建时间的条目。读取器仅折叠该记录之前的事件，最多追溯 127 条父关系，不激活冷父运行、不改写父日志。父会话后来的办公关联不会追溯认领原生子会话；同一员工在子会话明确审核的新角色保留，祖先员工矛盾则限制该子会话。缺少匹配目录时，完整父链在所有时点均无办公声明，才可证明原生归属。父会话缺失，或具有办公归属的父会话缺少准确目录时，仍无法确认归属：办公历史过滤隐藏该子会话，直接投影读取返回不存在，模型／工具准入拒绝继续并提示从备份恢复。不会分配给当前员工或修改原记录。[旧子会话指南](../../../docs/upgrade-guide/v0.2.1-alpha.2/office-legacy-child-history/guide.zh.md) 说明部署及备份要求。

<a id="model-experience"></a>
## 模型体验

### 首页提示词交接

#### 模型看到什么

仅明确提交的请求会到达模型。`submit` 选项沿用已有队列提交流程和持久化会话历史。查看办公页面、发现技能、修改状态及编辑资料不会向模型增加上下文。事项协助及工具使用要求会先准备可见文字，由用户检查后提交。已保存关联贡献每次发送的不可变快照，包含未满足的依赖及配置就绪状态。选择技能引用不会加载指令；明确的原生技能调用继续使用已有 Host 加载器，并单独记录注入的指令。

#### Token 影响

办公读写不消耗模型 token。提交文字、捕获的关联文字及原生会话其他上下文决定请求 token。

#### KV Cache 影响

办公导航不会改写已有会话前缀。首页发送会创建新会话，缓存行为遵循原生模型运行时。

### 声明业务表单

#### 模型看到什么

这些表单直接调用办公 Remote。值和回执保留在员工办公 UI 及执行领域；表单不添加 Agent 消息、模型工具或提示词章节。可选原生办公工具独立持有模型可见的调用历史。

#### Token 影响

填写、审核、提交及浏览表单回执不发起模型请求。

#### KV Cache 影响

办公表单操作不改写原生会话消息或模型上下文。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与待办

- 集成目录支持登记、连接检查、私有会话关联、声明业务查询及经审核的员工写入表单。结果核查要求安装具体的客户适配器实现。审核关联进入原生模型上下文，可选办公工具可创建内部任务／待办，并经原生审批读取或提交选中公司系统声明的操作。工具页准备原生技能及任务要求；可见不代表已配置模型或依赖。网盘引用支持 1 MiB 以内的 UTF-8 文本、有界 PDF 可选文本、DOCX 正文段落／表格单元格、保存的 XLSX 单元格，以及明确选择的 PPTX 正文／备注文本；公式重算、其他 Office 格式及 OCR 继续待办。
- 支持持久草稿的服务端可在确认后跨浏览器刷新保留私聊消息、已发送文件及各联系人文本／文件草稿。文字延迟 350 ms 保存，关闭窗口可能丢失未确认的文字或文件编辑。保存失败保留本地输入以便重试；并发修改时明确选择加载已保存草稿或保留此窗口输入。群聊仍待实现。
- 已提供邀请答复、状态取消、会议内容和成员编辑、可见日程重叠提示及按配置启用的内部成员忙闲。外部日历忙闲／送达、重复和跨日日程仍待实现。
- 首页尚未发送的 File 句柄只属于当前浏览器窗口，关闭或刷新会丢失；已接纳附件和后续发送失败沿用原生会话所有权。事项关联是浏览器本地导航状态，不提供跨设备身份或授权边界。刷新可恢复原生文字草稿和历史；关闭窗口后，未发送的原生附件句柄需要重新选择。
- 独立办公网关已提供集中密码登录；SSO、目录同步和多因素认证继续待办。员工本机 Host 是受信任环境；固定身份及集中办公登录均不构成面向该 Host 管理员或原生 Agent 工具的认证边界。

### 开发备注

账号／联系人字典只读取自身保存的条目。`constructor`、`__proto__` 和 `toString` 等员工编号继续有效；缺少草稿、错误或授权记录时，不读取 JavaScript 原型上的值。真实存储重启和浏览器验收覆盖这些身份的消息、草稿恢复及共享账号条件。

客户端 UUID 和文件编码使用仓库的 crypto 工具，因此在浏览器未提供安全上下文专属 `crypto.randomUUID` 方法时，例如普通 HTTP 内网页面，草稿、消息和上传仍可工作。浏览器验收会主动移除此方法，并保留旧式输入法的 Enter 处理。UI 回调明确声明无上下文的 `this` 类型，await 后的销毁检查继续保留。

客户端代码位于 [src/client](src/client)，Host Remote 适配器位于 [src/index.ts](src/index.ts)。Agent 执行继续使用原生会话管线，业务授权保留在办公服务中。

当前 Remote 载体精确检查参数位置。读取最新聊天时需同时传入联系人和显式的 `undefined` 游标。[聊天浏览器验收](../../../apps/web/tests/enterprise-office-chat.e2e.ts)覆盖此生成边界、消息接收、联系人草稿和 Host 控制的身份更换。
