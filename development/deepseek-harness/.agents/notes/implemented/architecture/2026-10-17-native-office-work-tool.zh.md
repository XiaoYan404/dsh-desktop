# Agent Note: 将内部办公工作绑定到领取的原生输入

Status: implemented

[English](2026-10-17-native-office-work-tool.md) | 中文

## 问题

已提交的提醒关联记录员工意图，但不会创建办公工作。增加全局创建工具会向无关会话暴露能力。在 `agent/pre-step` 绑定工具对首次请求已经太晚：原生循环先组装工具 schema，再运行该瀑布流。审批也可能比员工选定的关联或插件存活更久。

## 决策

按需启用的 `tool-office` Host 消费方提供一个内部工作工具。每条被领取的用户消息提供自己不可变的准备提醒快照。领取通知先于提示词组装，因此准确的 Agent 作用域会在首次收集 schema 前获得工具。之后的用户输入替换绑定，非用户上下文不能授予绑定。轮次结束、Agent 销毁及插件卸载会移除准确的注册，不销毁原生 Agent 作用域或其他工具。

工具要求准确的当前调用驱动，并由快照、Agent 和原生调用编号推导稳定的执行 UUID。员工 BFF 选择已认证的操作者。[办公预留操作](2026-10-17-office-agent-work-reservations.zh.md)负责当前授权、持久创建和重试恢复；历史提示词元数据是描述性证据，不是执行权限。

默认策略增加已有的原生人工审批请求。显式自动设置只省略这项额外请求，保留所有其他原生拒绝和审批关卡。操作在等待 BFF 前后检查插件及执行生命周期。卸载会中止后续执行并移除可见性；业务已提交后发生取消不能回滚该写入。

办公请求也提供不可变执行字段及已解析默认负责人的完整双语审核信息。其他策略已请求审批时，原原因及语言条目继续保留。带引号的文字防止内嵌换行冒充字段标签。原审批卡保留这些标签，并在滚动区内对长值换行，同时保持决定按钮可见。审核不能替代确认后的服务端授权。

同一领取边界仅在提交捕获中含有已选且已配置的系统时，提供目录／读取工具。领取是同步通知，因此发现保留为显式模型工具调用，不成为异步注册副作用。办公服务端核查当前私有捕获归属、角色、关联版本及连接版本，读取还保留发现所返回的提供方版本。独立的人工读取审批显示准确系统、动作、员工及版本，其他原生决定仍有约束力。普通工具结果记录将目录元数据及真实业务字段传入后续模型输入。消费方持有每个已注册名称及释放句柄，名称冲突既不覆盖其他工具，也不对其增加办公审批。

已选系统还提供独立的业务写工具。目录输出包含已安装写支持及冻结的公共字段声明。独立的人工写审批展示系统、动作、员工、准确版本及每个名称唯一的文本行，不改写值。同一原生调用身份沿用内部工作的重试 UUID 推导。外部写入协调器持有当前授权、持久派发及权威／未知回执语义。不同原生调用不能重放相同未决业务值。真实回执追加到原生历史及后续模型输入，不替换原 Session 格式或全局工具。

原生消费方在通用工具运行时格式化诊断消息前，隔离 BFF 意外失败。稳定错误保留原始私有 cause，结构化业务拒绝继续使用原有处理码。这防止适配器含凭据的异常进入模型输入或持久工具结果文字，同时不把失败或未知写入结果转成成功。

提交的 PDF 引用沿用同一输入领取注册点及原生读取审批。办公授权服务在获取字节前及返回解析文本前，核查准确的已审核版本与当前文件权限。完整二进制附件副本可能超出办公授权的有效期，因此该读取器仅通过原有工具结果日志输出有界页面文本，不保留文档缓存。每次解析由可释放的独立 Worker 负责，使用可配置的输入、页数、字符、输出、期限及 V8 堆上限；操作返回前等待终止完成。解析工作因此不阻塞 Host 事件循环，取消也可实际生效。原 UTF-8 读取器保留独立上限。

旧父链属于限制证据，找不到证据不能证明原生范围。历史披露及模型／工具准入拒绝未确认的子会话，不回退到其空白本地折叠。完整保留父链没有任何办公声明时，无需目录边界即可证明原生归属；存在办公归属的父会话仍需准确的创建边界。新 runtime 子运行先恢复父归属再继承，为原生子运行保留当前进程中的证据。这样保留原日志，且不会在备份证据缺失时虚构员工归属。

## 考虑过的替代方案

**在步骤准备之后注册。** 执行能找到定义，但首次模型请求缺少 schema。领取边界保留原循环顺序，无需修改核心执行。

**注册全局办公工具并依靠描述。** 描述不能约束选择、作用域或当前业务权限。

**使用同一个 Agent 键再建作用域。** 原生 Agent 已拥有该作用域。消费方只拥有注册的移除句柄，不拥有 Agent 共用注册表的生命周期。

**将审批当成持久业务授权。** 员工可在等待审批时取消提醒关联。新业务写入前，服务会复核当前权限。

## 验证

无需密钥的浏览器模型回复执行真实原生工具和持久办公操作。覆盖已提供的 schema、原文件工具、一条真实工作、稳定回执重试、工作页刷新及不变的会话事件。原生审批允许或拒绝创建；等待审批时取消关联，之后点击允许会被拒绝。审批期间卸载会阻止写入，并保留原 Agent 和文件工具。第二个活跃原生 Agent 保有原工具，但不会获得等待审批会话的办公工具。

## 影响

定向 PDF 测试执行真实二进制解析、完整输出预算及 Worker 取消。真实浏览器在网盘选择 PDF、审批第二页、比对持久结果与后续模型输入，并在祖先访问权撤销后拒绝第二次读取。页面文本预期独立于原生图片和文件快照。

企业补丁开启这个可选消费方，普通 Web 组合保持关闭。提交的提醒请求可通过原生审批创建内部任务或待办。外部公司系统写入需要独立执行器。员工 Host 仍是受信任环境；这个消费方不会将办公身份与其管理员或独立配置的原生工具隔离。
