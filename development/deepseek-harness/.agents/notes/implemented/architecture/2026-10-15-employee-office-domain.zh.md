# Agent Note: Employee office data stays separate from Agent execution

Status: implemented

[English](2026-10-15-employee-office-domain.md) | 中文

## Problem

员工任务、待办和日程邀请具有负责人、收件人和企业权限。Harness 的 Todo、Goal、Schedule 描述 Agent 的工作与后续提示。将这些记录当作员工日历，会把人工状态变更与模型执行耦合，也无法提供收件人授权和持久化邀请。

## Decision

[办公服务](../../../../packages/enterprise/office/README.zh.md)拥有独立且有版本的 StorageDomain。它接受受信任的操作者身份，在每次操作中检查成员是否活动，并在生成当日视图前过滤授权范围。操作者 ID 不是认证凭据，传输适配层必须先认证调用者。

一次领域提交同时保存事项、参与状态、收件箱记录及审计。单个所有者串行执行读取、修改和写入，并以事项版本拒绝过期修改。服务在持久化后发布变更，所有观察者运行后统一处理观察者错误。关闭时停止接收新操作，并等待已经接收的写入完成后关闭领域。

服务在构造时保存所属 fiber。Cordis 会将服务的 `ctx` 绑定到调用者，因此公开方法读取 `this.ctx.fiber` 可能检查的是调用者生命周期，导致服务正在卸载时仍错误接收新操作。

私聊文件消息使用独立声明领域和不可变对象目录，不向原有持久化文字消息头增加字段。所有字节就绪后，原消息头提交决定发布；文件账本可据此恢复结果不确定的最终回执。写入字节前持久化文件标识，使中断发送可依据所属记录回收，无需扫描文件系统猜测归属。保留的正数聊天水位避免将原聊天单元丢失误当作消息未发布。备份必须同时保留这三个部分。

现有[领域存储设计](../../proposed/architecture/2026-07-24-domain-kv-storage-and-workspace.zh.md)继续定义存储规则。本决策增加办公消费者，不修改 Session 格式、Agent 循环、工作区记录、CLI/SDK 入口或现有定时任务。

未发送文件草稿使用独立受限原子单元，保存规范字节、联系人版本及发送标识。每次替换草稿无需决定文件系统归属及清理，显式员工／全公司逻辑额度限制增大的编码快照。已发送文件继续使用不可变对象目录。消息发布前持久化准确的草稿发送，使清除失败时可依据原消息恢复，不重复发送或清除新选择。

连接配置使用独立领域，不向说明性清单导入增加地址或密钥。由部署持有的来源和凭据别名策略约束办公管理员可连接的目标，管理员不能选择任意环境模型凭据或网关凭据。只有所属办公服务端在每次操作时通过自己的凭据提供方解析别名，复用凭据轮换和存储规则，同时不向员工 Host 暴露中央凭据值。配置就绪与单次网络检查是不同事实，原生 MCP／插件安装继续由原有模块负责。

连接器声明将发现与执行分开。准确允许角色及进程内提供方版本，防止元数据快照授权其他员工或替换后的实现。读取回调接收服务端持有的员工身份和私有连接输入，员工传输仅接受已声明动作及版本坐标。结构化纯文本字段限制页面可渲染内容，避免将任意远程文档当作可执行内容。此只读边界将客户写入幂等及持久执行审计留给独立所有者；导入清单或查看目录不会产生这些能力。

## Alternatives considered

**复用 Agent Todo 和 Schedule。** 这些记录用于 Agent 计划和提示发送。员工邀请和按收件人授权需要独立生命周期，复用会改变现有语义。

**将业务记录保存在组件 store。** 这样既无法在 Host 重启后保留办公数据，也不能对非 UI 调用者执行授权检查。

**没有事务地逐条写入不同记录。** 第二次写入失败可能留下没有邀请或通知的会议。当前单单元后端可执行一次办公原子提交；后续集中事务提供方可扩容，但不能宣称 JSON 文件可协调多个 Host。

## Consequences

办公包按需启用并提供业务操作，独立 UI 和认证网关包消费这些操作。聊天、文本／文件草稿、文件消息和网盘拥有各自持久化领域。多个员工 Host 连接到单个集中办公写入所有者，不并发修改共享 JSON 文件。完整快照仍随历史增长，可扩展事务存储和客户连接器执行继续独立跟踪。各 UI 负责自己的草稿保存确认及恢复流程。

Loader 组合测试使用真实 JSON 后端，覆盖事项和回复持久化、授权、过期写入、无效输入、通知失败、重启和提交未完成时卸载。无密钥快照固定有权员工的当日输出。这些测试不代表 SSO、外部日历发送或完整企业 UI 已经完成。
