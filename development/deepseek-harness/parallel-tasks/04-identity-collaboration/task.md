## 邀请与身份必须保留的语义

- 邀请默认关闭，配置期限／容量；只给 active 且未设凭据成员生成首密邀请码。独立 v1 hash 台账只存摘要，原 identity v1 原子写首次凭据；任何已有凭据都阻止旧 code 再设密。

- 原 requestId 的已确认重试只返回元数据；邀请码丢失须撤销后重签。code 只在当前组件一次显示、显式复制后由管理员自行交付；关闭清除，不能写共享快照或浏览器存储。

- 接受成功只预填成员账号并回原登录，不创建登录会话、不替换 Host 凭据、不隐式创建成员或授角色。备份／恢复必须同时理解目录、identity 和邀请码台账的一致性。

- T063 实现可配置企业身份提供方、离职回收、会话及连接器权限撤销和集中策略。所有身份映射由可信服务端确定，资料里的岗位／角色文字不授权限；SSO/MFA/目录同步按真实支持范围实现，不假造供应商兼容。
