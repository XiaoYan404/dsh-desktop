# 关联工作附件前升级办公读取器

[English](guide.md) | 中文

## 变更

任务和待办可关联最多 20 个已确认的网盘文件版本。关联不复制文件，也不授予网盘权限。附件视图对无权访问或版本已变化的文件不显示文件名。修改关联使待验收交付失效；提交和确认交付时，操作者必须能访问所有关联文件的当前已确认版本。退回仍可用于要求补充权限或修改资料。变更原子提交 `work_attachments_updated` 通知和审计，旧办公读取器会明确拒绝不支持的记录。没有附件的既有工作及原生会话格式保留原有行为。

## 迁移

1. 停止共用办公后端的员工 Host 和中央网关。备份后端；JSON 部署包括 `storage-json.root`。
2. 同时升级 Host 和网关，保留数据目录及存储配置。
3. 给未关闭的任务或待办关联网盘文件。单独核对文件权限，在要求其他员工提交或确认交付前通过网盘分享。文件版本变化后明确重新选择，再次提交交付。
4. 降级须恢复升级前配套的办公存储备份。保留原生会话目录。
