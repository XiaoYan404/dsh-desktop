# 编辑事项内容前升级办公读取器

[English](guide.md) | 中文

## 变更

编辑任务或待办会在 `enterprise_office` 保存 `work_updated` 通知和审计记录。旧办公读取器会拒绝此类型。当前读取器可接受既有记录，领域保留版本 1，因为旧枚举校验器会明确拒绝新增判别值。已有任务标识、操作历史和原生 Session 格式保持完整。

## 迁移

1. 停止共享办公后端的员工 Host 和集中网关。备份对应后端，使用 JSON 时包含 `storage-json.root`。
2. 调用 `updateWork` 或编辑任务／待办内容前，同时升级员工 Host 和集中网关。保留既有存储配置和数据目录。
3. 打开已有任务，修改标题或截止信息后，确认标识、负责人、状态及已有操作历史仍可用。确认其他有权参与者收到更新通知。
4. 降级时仅恢复对应的升级前办公存储备份。保留原生 Session 目录；之后的办公修改不包含在该备份中。
