# 接受或转交任务前升级办公读取器

[English](guide.md) | 中文

## 变更

接受、拒绝或转交任务会在 `enterprise_office` 领域保存操作历史，并写入新增的 `task_accepted`、`task_rejected` 或 `task_transferred` 通知和审计类型。旧办公读取器会拒绝这些类型。当前读取器可接受既有办公记录；领域保留版本 1，因为旧读取器会明确拒绝新增判别值，能够安全处理。原生 Session 日志格式保持不变。

## 迁移

1. 停止共享办公后端的员工 Host 和集中网关。备份对应后端，使用 JSON 时包含 `storage-json.root`。
2. 调用 `decideTask` 或使用任务操作按钮前，同时升级员工 Host 和集中网关。保留既有存储配置和数据目录。
3. 打开已有任务，接受或转交后确认标识保持不变、操作历史包含操作者和相关负责人，且接收人收到通知。
4. 降级时仅恢复匹配的升级前办公存储备份。保留原生 Session 目录；备份之后的修改不包含在旧办公存储中。
