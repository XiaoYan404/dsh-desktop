# 添加工作子任务前升级办公读取器

[English](guide.md) | 中文

## 变更

任务和待办可保存最多 100 个清单子项，包含服务端生成的编号、标题和完成标记。子项继承父事项权限，不作为独立委派工作。清单变化一并提交 `work_subtasks_updated` 通知和审计，使旧办公读取器明确拒绝相关记录，避免丢弃新数据。当前读取器兼容没有清单的既有事项。办公域版本仍为 1，Native Session 格式不变。

## 迁移

1. 停止共享办公后端的员工 Host 与中央网关。备份后端，JSON 部署时包括 `storage-json.root`。
2. 编辑工作子任务前一并升级员工 Host 和网关，保留存储配置及数据目录。
3. 打开任务或待办维护清单，确认新增、改名、完成和移除子项后，父事项标识、负责人、截止时间、优先级及状态保留。检查另一参与人的更新通知，并确认重启后可恢复。
4. 降级只能恢复对应的升级前办公存储备份。保留 Native Session 目录；备份不包含升级后的办公变更。
