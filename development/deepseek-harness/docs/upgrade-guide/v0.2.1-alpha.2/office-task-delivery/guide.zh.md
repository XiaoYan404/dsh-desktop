# 提交任务交付前升级办公读取器

[English](guide.md) | 中文

## 变更

[工作归档和回收站操作](../office-work-lifecycle/guide.zh.md)暂停活跃交付操作。恢复保留历史，但事项修订号已变化，须重新提交交付。

事项有[已确认的网盘附件](../office-work-attachments/guide.zh.md)时，提交和确认均须能访问这些当前版本。附件变更使待验收提交失效；仍可退回以要求修正文件或权限。

进行中任务的负责人可填写说明提交交付，发起人或管理员填写说明，确认或退回当前未变更的提交。确认后任务完成；中间任何事项修订都会使提交过期，需重新提交。任务进入交付流程后，普通 `setStatus` 不能完成该任务，须经 `reviewTaskDelivery` 确认；没有交付历史的旧任务保留原状态操作。新增交付历史以及 `delivery_submitted`、`delivery_accepted`、`delivery_returned` 通知和审计会使旧办公读取器拒绝相关记录。当前读取器兼容既有事项。办公域版本仍为 1，Native Session 格式不变。

## 迁移

1. 停止共享办公后端的员工 Host 与中央网关。备份后端，JSON 部署时包括 `storage-json.root`。
2. 提交交付前一并升级员工 Host 和网关，保留存储配置和数据目录。
3. 接受任务后以负责人身份提交交付，再由发起人退回或确认，检查说明、通知和历史。工具完成已有交付历史的任务时须使用明确的审核确认操作，不能通过普通状态修改跳过验收。
4. 降级只能恢复对应的升级前办公存储备份。保留 Native Session 目录；备份不包含升级后的办公变更。
