# 归档或删除工作前升级办公读取器

[English](guide.md) | 中文

## 变更

任务和待办的发起人或管理员可按已查看修订号确认归档、移入回收站及恢复，操作必须填写说明。非活跃事项离开日常工作、日历统计及活跃事项操作；有权员工仍可在归档和回收站查看只读记录。恢复保留编号、分派、期限、子项、附件及业务历史。不会删除原生会话或网盘文件。变更使待验收提交失效，并原子保留操作历史、通知和审计。新增 `work_archived`、`work_deleted`、`work_restored` 记录让旧办公读取器明确拒绝不支持的数据，防止将非活跃事项重新显示为日常工作。

## 迁移

1. 停止共用办公后端的员工 Host 和中央网关。备份后端；JSON 部署包括 `storage-json.root`。
2. 同时升级 Host 和网关，保留存储配置和数据目录。
3. 确认归档一个任务并删除一个待办。以双方身份检查日常视图、归档和回收站，恢复后核对内容和审计历史。
4. 降级须恢复升级前配套的办公存储备份。保留原生会话及网盘对象目录。
