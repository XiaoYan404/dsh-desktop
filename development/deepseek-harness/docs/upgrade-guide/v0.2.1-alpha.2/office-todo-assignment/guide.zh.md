# 转交待办前升级办公读取器

[English](guide.md) | 中文

## 变更

`decideTask` 的 transfer 操作也可转交未关闭待办，并在 `enterprise_office` 保存负责人变更历史及 `todo_reassigned` 通知和审计记录。旧办公读取器会拒绝此类型。当前读取器可接受既有数据，领域保留版本 1，因为旧枚举校验器会明确拒绝新增判别值。原生 Session 格式保持完整。

## 迁移

1. 停止共享办公后端的员工 Host 和集中网关。备份对应后端，使用 JSON 时包含 `storage-json.root`。
2. 转交待办前，同时升级员工 Host 和集中网关。保留既有存储配置和数据目录。
3. 说明原因，将已有待办转交给其他启用成员。确认标识和截止信息保留、状态变为待处理、负责人变更历史可查，且接收人收到通知。
4. 降级时仅恢复匹配的升级前办公存储备份。保留原生 Session 目录；之后的办公修改不包含在该备份中。
