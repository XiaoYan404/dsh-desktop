# 修改日程成员前升级办公读取器

[English](guide.md) | 中文

## 变更

主办人和管理员可按已查看的修订号增删未关闭日程的受邀成员，主办人始终参与。仅改成员时保留原答复，修改日期或时间会要求受邀人重新答复。新增成员收到邀请；被移除成员失去普通日程读取权限，并收到保留此前标题的通知。必填审计类型 `schedule_members_updated` 和通知类型 `schedule_removed` 会使旧办公读取器拒绝相关记录。当前读取器兼容已有数据。办公域版本仍为 1，Native Session 格式不变。

## 迁移

1. 停止共享办公后端的员工 Host 和中央网关。备份后端，使用 JSON 时包括 `storage-json.root`。
2. 修改日程成员前，一并升级员工 Host 和网关，保留存储配置与数据目录。
3. 编辑已有日程，增删成员并验证邀请、移除通知和读取权限。既有 `updateSchedule` 调用省略 `inviteeIds` 时保留成员；显式传空数组仅保留主办人。
4. 降级只能恢复对应的升级前办公存储备份。保留 Native Session 目录；备份不包含升级后新增的办公变更。
